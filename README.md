# SEEKBLACK

SEEKBLACK is an independent digital product design and development studio portfolio.

> Design × Development × Delivery

The website is built to let potential clients understand the studio's services, review case studies, and verify implementation quality through interactive live demos.

## Live

- Website: https://seekblack.cn/
- NØRTH Case Study: https://seekblack.cn/work/north/
- FLOW Case Study: https://seekblack.cn/work/flow/
- MOTION Case Study: https://seekblack.cn/work/motion/

## What this repository contains

- Studio landing page
- Selected Work presentation
- NØRTH / FLOW / MOTION case studies
- Services, process and working principles
- Contact / WeChat modal
- Responsive layout and motion system
- SEO basics: canonical, Open Graph, sitemap and robots.txt
- Reduced-motion accessibility support

## Stack

- Semantic HTML
- CSS
- Vanilla JavaScript
- No animation framework dependency
